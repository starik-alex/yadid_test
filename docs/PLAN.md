# План и решения

## Цель каждой страницы

| Страница | Одно целевое действие | Метрика |
|---|---|---|
| `/` квиз | Оставить телефон после квиза | Конверсия посетитель → лид; доля «высоких» лидов |
| `/webinar` | Зарегистрироваться и подтвердить участие | Конверсия посетитель → регистрация; доля пришедших |

Одна страница — одна цель — одна главная кнопка на экране. Вторичные действия (WhatsApp, переход на вебинар) визуально слабее.

## Почему квиз, а не обычная форма

Сразу просить телефон — страшно, и человек уходит. Поэтому сначала пять простых вопросов, по одному нажатию на каждый. Каждый ответ — маленькое «да», и к концу оставить контакты уже легче (принцип последовательных шагов).

Ещё два приёма:

1. **«"Не знаю" — тоже хороший ответ».** Снимает страх ответить неправильно. У каждого вопроса есть вариант «не знаю», и он даёт баллы: человек с одними «не знаю» получает «средний», а не «низкий» результат.
2. **Результат до формы.** Перед полями человек видит «Похоже, есть хорошая база для права на гражданство». Это причина дописать контакты.

### Скоринг

| Вопрос | Лучший ответ | Баллы |
|---|---|---|
| Кто жил в Германии/Австрии до 1945 | родитель / дедушка или бабушка | 3 (прадед — 2, не знаю — 1) |
| Когда уехали | 1933–1945 | 3 (до 1933 — 2, после 1945 / не знаю — 1) |
| Остались ли документы | да | 3 (частично — 2, не знаю — 1, нет — 0) |
| Есть ли свидетельства о рождении по цепочке | да, все | 2 (часть / не знаю — 1, нет — 0) |
| Для кого проверка | для себя и детей | 2 (остальные — 1) |

Максимум 13. Порог «высокий» ≥ 10, «средний» ≥ 5. Оценка стоит в теме письма юристу.

## Структура `/`

1. Шапка: логотип и кнопка «Проверить».
2. Первый экран: заголовок-вопрос, одна строка пояснения, главная кнопка, 4 карточки доверия.
3. Квиз в стеклянной карточке: прогресс, вопрос, 4 варианта, «не знаю — тоже ответ», «назад».
4. Результат и форма: имя, телефон, e-mail (по желанию), 2 галочки.
5. Экран успеха с галочкой и предложением вебинара.
6. Как это работает — 3 шага.
7. Тёмный блок-приглашение на вебинар.
8. FAQ — 5 частых страхов.
9. Подвал: контакты, политика конфиденциальности, заявление о доступности.
10. На телефоне — нижняя панель «Проверить» и WhatsApp. Она прячется, когда на экране сам квиз.

## Структура `/webinar`

1. Заголовок-тема, дата и время (из `config.js`, по часовому поясу Израиля), длительность.
2. Четыре пункта «что вы узнаете».
3. Форма: имя, e-mail (туда придёт ссылка на Zoom), телефон по желанию, **«подтверждаю участие»** (обязательно), согласие с политикой, рекламная галочка.
4. Успех: «Вы зарегистрированы», кнопки Google Calendar и .ics для Apple/Outlook.

## Состояния, которые нарисованы

- **Обычное** — каждый шаг квиза.
- **Выбрано** — синяя рамка и галочка в кружке.
- **Ошибка** — красная рамка, светло-красный фон и понятный текст под полем («Номер телефона выглядит неверно — например 050-1234567»). Фокус переходит на первое поле с ошибкой.
- **Загрузка** — кнопка неактивна, текст «שולח…» («Отправляю…»).
- **Успех** — зелёный круг с галочкой и следующий шаг.
- **Сбой отправки** — сообщение с предложением написать в WhatsApp.
- **Превью** — плашка «предпросмотр», формы не отправляются.

## Технические решения

- Без фреймворков: страница весит несколько десятков КБ и открывается быстро даже по мобильному интернету.
- Vercel: статика из `public/` и две функции в `api/`.
- FormSubmit вместо своей почтовой системы: бесплатно, без хранения персональных данных у нас. Ограничение — разовая активация по письму.
- Вопросы и баллы в одном файле (`public/js/scoring.js`) для браузера и сервера, чтобы они не расходились.
