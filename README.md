# Лендинги для «Ядид и партнёры» (Yadid & Co.)

Две страницы на иврите для рекламного трафика израильской юридической фирмы Давида Ядида, которая помогает получать европейское гражданство:

| Страница | Адрес | Цель |
|---|---|---|
| Проверка права на гражданство | `/` | Квиз из 5 вопросов → результат → контакты. Заявка (лид) с оценкой «высокий / средний / низкий» уходит на почту юриста. |
| Регистрация на вебинар | `/webinar` | Бесплатная лекция в Zoom: имя, e-mail, подтверждение участия. После регистрации кнопки «добавить в календарь». |

Плюс обязательные страницы `/privacy` (политика конфиденциальности) и `/accessibility` (заявление о доступности по израильскому стандарту).

Без фреймворков и зависимостей: статический HTML/CSS/JS и две серверные функции Vercel.

## Быстрый старт

Нужен Node.js 18 или новее.

```bash
npm test        # 47 тестов: скоринг, API, HTML/CSS, длина рекламных текстов
npm run dev     # http://localhost:5173 — сайт и API вместе
```

`npm run dev` по умолчанию работает в режиме `DRY_RUN=1`: формы проходят до конца, а письмо не отправляется, только печатается в терминале. Чтобы отправить по-настоящему: `DRY_RUN=0 npm run dev`.

`npx serve public` тоже покажет страницы, но без API: формы будут возвращать ошибку. Для проверки форм используйте `npm run dev` или `npx vercel dev`.

## Публикация на Vercel

```bash
npx vercel          # первый раз: войти, создать проект, получить preview-ссылку
npx vercel --prod   # выложить в продакшн
```

Или через сайт: vercel.com → Add New → Project → Import из GitHub-репозитория → Deploy. Настройки сборки не нужны: `vercel.json` уже указывает папку `public` и короткие адреса (`/webinar` вместо `/webinar.html`).

Переменные окружения (Vercel → Project → Settings → Environment Variables), все необязательные:

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `LEAD_EMAIL` | `tal.g@yadidlaw.com` | Куда приходят заявки |
| `SITE_URL` | `https://yadid-landing.vercel.app` | Адрес сайта для FormSubmit; поставьте свой домен |
| `DRY_RUN` | не задано | `1` — не отправлять письма (для тестового стенда) |

### Обязательно после первого запуска: активировать FormSubmit

Письма отправляет бесплатный сервис [FormSubmit](https://formsubmit.co). При **первой** заявке он присылает на `LEAD_EMAIL` письмо «Confirm your email». В нём нужно один раз нажать кнопку подтверждения. До этого заявки не доставляются, и API возвращает ошибку `502 delivery_failed`.

Порядок: выложить сайт → отправить тестовую заявку → открыть почту tal.g@yadidlaw.com → подтвердить → отправить ещё одну тестовую заявку и убедиться, что она пришла.

```
  privacy.html          политика конфиденциальности
  accessibility.html    заявление о доступности
  css/styles.css        все стили; токены совпадают с design/tokens.json
  js/config.js          настройки: WhatsApp, дата вебинара
  js/scoring.js         вопросы квиза и баллы — общий файл для браузера и сервера

  js/quiz.js            логика квиза
  js/webinar.js         дата вебинара, форма, ссылки «в календарь»
  assets/               иконка и картинка-превью для соцсетей (1200×630)
api/
  lead.js               POST /api/lead — пересчитывает баллы и шлёт письмо
  webinar.js            POST /api/webinar — регистрация на вебинар
  _lib/common.js        проверка полей, защита от ботов, отправка в FormSubmit

  dev-server.js         локальный сервер без зависимостей
```

### Скоринг

У каждого ответа есть баллы (`public/js/scoring.js`), максимум 13:

- **высокий** — 10 и больше;
- **средний** — 5–9 (сюда попадает человек, который на все вопросы ответил «не знаю»);
- **низкий** — меньше 5.

Сервер **пересчитывает** баллы сам: оценке из браузера не доверяем. Оценка стоит в начале темы письма, например `[גבוה] ליד חדש — בדיקת זכאות לאזרחות גרמנית — <имя>`, чтобы юрист сначала звонил самым перспективным.

### Режим превью

Если страница открыта как файл, во встроенном превью (например, артефакт claude.ai) или с параметром `?preview=1`, сверху появляется плашка «תצוגה מקדימה» («предпросмотр»). Формы в этом режиме показывают экран успеха, но ничего не отправляют: площадки превью всё равно блокируют запросы наружу.

### Защита и закон

- Скрытое поле-ловушка `_gotcha` для ботов: если оно заполнено, заявка тихо отбрасывается.
- Согласие с политикой конфиденциальности обязательно и проверяется на сервере (`consent === true`).
- Согласие на рекламную рассылку — отдельная галочка, по умолчанию **не** отмечена (статья 30א израильского закона о связи). Тест это проверяет.
- Доступность (ת"י 5568 / WCAG 2.0 AA): квиз проходится с клавиатуры, у полей есть подписи, ошибки озвучиваются экранным диктором, при «уменьшении движения» анимации выключаются.

## Тесты

```bash
npm test
```

- `tests/scoring.test.js` — баллы, пороги, защита от подделанных ответов.
- `tests/api.test.js` — оба API с подменённым `fetch`: успех, ошибки полей, ловушка для ботов, сбой FormSubmit, неверный метод, битый JSON.
- `tests/campaign.test.js` — заголовки Google Ads не длиннее 30 символов, описания не длиннее 90.
- `tests/static.test.js` — у всех страниц `lang="he" dir="rtl"`, у каждого поля есть подпись, рекламная галочка не отмечена, все подключённые файлы существуют, токены дизайна совпадают с CSS.
